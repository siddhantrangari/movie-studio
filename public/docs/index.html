⚡ What is Movie Studio MCP?

The Model Context Protocol (MCP) server enables AI agents (Claude Desktop, Antigravity IDE, custom scripts) to directly control LTX 2.5 video generation, RunPod GPU provisioning, storyboarding, and server-side ffmpeg film assembly.

🚀 Automated Workflow

Automatically boot GPU pods on demand, write shot storyboards with native audio/narration, generate multi-scene video clips, assemble 1-minute films with crossfades & captions, and retrieve presigned Cloudflare R2 video links.

⚙️ Client Configuration & Setup

1. Claude Desktop Config

Add to claude_desktop_config.json:

{
  "mcpServers": {
    "movie-studio": {
      "command": "npx",
      "args": [
        "tsx",
        "--env-file=/path/to/movie-studio/.env.local",
        "/path/to/movie-studio/mcp/server.ts"
      ]
    }
  }
}

2. Standalone Terminal Execution

Run directly in terminal via stdio JSON-RPC:

npm run mcp

🛠️ MCP Tools Reference

movie_create_character CHARACTER CONSISTENCY

Creates a consistent character profile with visual appearance traits and an optional base64 reference portrait used to seed LTX 2.5 frame-1 generation.

ParameterTypeDescription
namestringCharacter name (e.g. "Captain Ethan")
descriptionstringAppearance details appended to prompts for consistency
imageBase64stringOptional Base64 PNG/JPG reference image for LTXVImgToVideo
movie_list_characters GET CHARACTERS

Returns a list of all saved character profiles and their reference image files.

movie_pod_status GET STATUS

Returns GPU pod health, ComfyUI availability, warm/cold start status, streaming boot log, and RunPod account balance.

// Example Call: {}
// Returns: { "podId": "kjiafppb7kdbtg", "ready": true, "balance": 45.20 }
movie_pod_start PROVISION

Provisions or resumes an LTX 2.5 GPU pod on RunPod (Secure Cloud RTX 4090). Downloads models into volume and initialises ComfyUI v0.33.1.

movie_pod_stop TERMINATE

Terminates the active GPU pod instantly to prevent unnecessary billing.

movie_create_storyboard SCRIPT GENERATION

Creates a new film storyboard with structured scene prompts, camera movements, audio modes, and narration voice settings.

ParameterTypeDescription
titlestringTitle of the film project
resolutionstring"1280x704" (Max), "1024x576" (HD), or "704x384" (Draft)
audioModestring"native" (LTX audio), "elevenlabs" (narration), or "both"
scenesarrayArray of scene objects with prompts and camera settings
movie_generate_scene COMFYUI RENDER

Triggers LTX 2.5 video clip generation for a single scene on the active GPU pod.

movie_assemble_film FFMPEG ASSEMBLY

Pulls rendered scene clips from pod, crossfades video, mixes audio, burns ASS captions, and uploads completed MP4 to Cloudflare R2.

movie_get_film PRESIGNED URL

Fetches assembly status and direct presigned Cloudflare R2 streaming/download link.

🤖 Complete Autonomous Pipeline Example

Here is how an AI agent uses the MCP server to produce a 1-minute film using LTX 2.5 or MiniMax Hailuo 3:

  1. 1 Call movie_pod_start with {"model": "minimax"} or {"model": "ltx25"} to spin up GPU pod.
  2. 2 Call movie_create_storyboard with 12 scenes (5s each @ Max quality).
  3. 3 Iterate through scenes calling movie_generate_scene with {"model": "minimax"} to render clips on ComfyUI.
  4. 4 Call movie_assemble_film to mix narration, crossfade scenes, and upload to Cloudflare R2.
  5. 5 Call movie_pod_stop with {"action": "terminate"} to shut down GPU pod billing.
  6. 6 Call movie_get_film to receive the 302 presigned Cloudflare R2 video URL.
